# 테니스협회 홈페이지 샘플

테니스협회 홈페이지 시연용 프로토타입입니다.

- `index.html` : PC 버전
- `mobile.html` : 모바일 버전

## 주요 기능
협회 홈페이지, 관리자 페이지, 개인회원·클럽팀 관리, 대회 접수, 참가자 관리,
자동 조편성·대진표, 코트·경기시간 자동 배정, 내 경기 확인, 경기 결과 입력,
조별리그 순위 자동 계산, 본선 대진 반영, 시즌 랭킹, 시립코트 예약·우천 취소, 엑셀 다운로드

## 시연
- 관리자 계정: admin / 1234
- 데이터는 각 사용자의 브라우저에만 저장됩니다(서버 없음).
- 관리자 대시보드의 "샘플 데이터 초기화"로 처음 상태로 돌릴 수 있습니다.
- 인물·클럽·코트 정보는 모두 샘플입니다.
